# Requisitos do RoutineOS

## Requisitos Funcionais

### RF01 — Cadastro de usuário

O sistema deverá permitir que o usuário crie uma conta.

### RF02 — Login

O sistema deverá permitir que o usuário realize login.

### RF03 — Gerenciamento de tarefas

O usuário poderá criar, editar, concluir e excluir tarefas.

### RF04 — Gerenciamento de rotina

O usuário poderá organizar suas atividades dentro de sua rotina.

### RF05 — Gerenciamento de hábitos

O usuário poderá cadastrar e acompanhar hábitos.

### RF06 — Dashboard

O sistema deverá apresentar uma visão geral da rotina do usuário.

## Requisitos Não Funcionais

### RNF01 — Segurança

Os dados dos usuários deverão ser protegidos.

### RNF02 — Responsividade

O sistema deverá funcionar em diferentes tamanhos de tela.

### RNF03 — Usabilidade

A interface deverá ser simples e intuitiva.
